# 짤/카드 스튜디오 (zzal-studio)

캔버스 기반 **한글 문구 이미지 편집기**입니다. 이미지를 불러와 문구의 위치·크기·색을 바꾸고, 1:1 / 4:5 / 9:16 세 화면비로 미리보기·내보내기를 할 수 있습니다. 편집 상태는 JSON으로 저장·복원되며, 내보낸 PNG에는 원본 메타데이터(EXIF/GPS)가 포함되지 않습니다.

> 단일 HTML 파일. 빌드·설치·외부 라이브러리 없음.

---

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 이미지 불러오기 | PNG · JPEG 지원, 드래그 앤 드롭 / 클릭 업로드 |
| 안전한 파일 처리 | 미지원 형식·손상 파일은 크래시 없이 안내 메시지 |
| 문구 편집 | 한글·혼합 문자·이모지(ZWJ) 지원, 줄바꿈 가능 |
| 스타일 조절 | 크기(12~120), 색상(#RRGGBB) |
| 위치 조정 | 캔버스 드래그 + X/Y 슬라이더 + 숫자 입력 + 방향 패드(0.1/0.5/1/5% 단위) |
| 화면비 | 1:1 · 4:5 · 9:16 (상대 좌표 기반이라 비율 전환에도 배치 유지) |
| 미리보기 = 다운로드 | 동일 렌더 로직으로 긴 변 1080px PNG 내보내기 |
| 메타데이터 제거 | 원본을 새 캔버스에 재렌더 → EXIF/GPS/기기정보 미포함 |
| JSON 저장/복원 | 편집 상태 저장, 정상/손상/필수 누락 3케이스 검증 후 복원 |
| 반응형 | 900px 이하 세로 배치, 600px 이하 모바일 터치 최적화 |

## 🚀 사용 방법

### 1. 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

```bash
# 저장소 클론
git clone https://github.com/<사용자명>/zzal-studio.git
cd zzal-studio

# 방법 A: 파일 직접 열기
open index.html          # macOS
start index.html         # Windows
xdg-open index.html      # Linux

# 방법 B: 로컬 서버 (권장)
python3 -m http.server 8000
# → http://localhost:8000 접속
